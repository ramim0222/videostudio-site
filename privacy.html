Privacy policy

Last updated: 25 November 2026

Video Studio is a private tool. Its only user is its owner, S. M. Ramim, who uses it to upload and schedule videos on the owner's own YouTube channel. This page explains what it does with data.

YouTube API Services

Video Studio uses YouTube API Services. By using it you agree to the YouTube Terms of Service, and the Google Privacy Policy applies.

What data it uses

  • Google sign-in: when the owner signs in, Google gives Video Studio an access token for the owner's YouTube channel. The token is stored only on the owner's computer, in a private file. It is never sent anywhere except to Google.
  • The channel's own information: the channel's name and its list of uploaded video titles, so that the same video is never uploaded twice.
  • The owner's own videos: each video file with its title, description, tags, thumbnail, subtitles, playlist and publish time, sent to YouTube to publish it.

What it does not do

  • It does not collect, store or process data of any other person.
  • It does not sell, rent or share any data with anyone, and it has no analytics or ads.
  • It stores nothing on any server: a list of what was uploaded stays on the owner's computer.

Removing access

Access can be removed at any time on the Google security settings page (Third-party apps with account access → Video Studio → Remove access). Deleting the private file on the owner's computer deletes the stored token.
