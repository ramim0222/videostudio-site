Privacy policy

Last updated: 25 November 2026

Video Studio Personal is a private tool. Its only user is its owner, S. M. Ramim, who uses it to upload and schedule videos on the owner's own YouTube channel, Facebook Page, Instagram account and TikTok account. This page explains what it does with data.

YouTube API Services

Video Studio Personal uses YouTube API Services. By using it you agree to the YouTube Terms of Service, and the Google Privacy Policy applies.

TikTok

Video Studio Personal uses TikTok's Login Kit and Content Posting API (upload to inbox). It only sends the owner's videos to the owner's TikTok inbox as drafts; the owner posts them in the TikTok app. The TikTok Privacy Policy applies to TikTok's side.

What data it uses

  • Google sign-in: when the owner signs in, Google gives Video Studio Personal an access token for the owner's YouTube channel. The token is stored only on the owner's computer, in a private file. It is never sent anywhere except to Google.
  • TikTok sign-in: when the owner signs in with TikTok, TikTok gives Video Studio Personal an access token for the owner's account, with two permissions: the account's basic profile (its display name, to show which account is connected) and uploading videos to the owner's inbox. The token is stored only in a private file on the owner's own server, and is never sent anywhere except to TikTok.
  • Meta access: a token for the owner's own Facebook Page and its Instagram account, stored only in a private file on the owner's computer and the owner's own server, and sent only to Meta.
  • The accounts' own information: the channel's name and its list of uploaded video titles, and the Page's and Instagram account's post captions, so that the same video is never uploaded twice; and, on TikTok, whether a draft sent to the inbox was posted.
  • The owner's own videos: each video file with its title, description, tags, thumbnail, subtitles, playlist and publish time, sent to the platforms to publish it.

Where data is kept

  • On the owner's computer: the private sign-in files and a list of what was uploaded.
  • On the owner's own server (a rented virtual server that only the owner controls): each planned video waits there until its time, and is deleted as soon as it is posted (a video that could not be posted is deleted after 48 hours), with a small record of what was posted and the TikTok sign-in file.

What it does not do

  • It does not collect, store or process data of any other person.
  • It does not sell, rent or share any data with anyone, and it has no analytics or ads.

Removing access

  • Google: on the Google security settings page (Third-party apps with account access → Video Studio (the name of the Google app) → Remove access).
  • TikTok: in the TikTok app, Settings and privacy → Security and permissions → Apps and services permissions → Video Studio Personal → Remove access.
  • Meta: Facebook Settings → Business integrations → Video Studio Personal → Remove.
  • Deleting the private files on the owner's computer and server deletes the stored tokens.
